# IAM Models and Scenarios Workshop

Workshop materials introducing integrated assessment models (IAMs), scenario
analysis, and the IAM pathways used to build prospective life-cycle inventory
databases with [`premise`](https://github.com/polca/premise).

## Learning objectives

By the end of the workshop, participants should be able to:

- explain what IAMs are and how they represent long-term transitions;
- distinguish models, scenarios, pathways, narratives, and quantitative outputs;
- interpret key IAM variables, regions, time horizons, and scenario assumptions;
- understand how `premise` translates IAM outputs into prospective life-cycle
  inventory databases; and
- identify important limitations and uncertainty when using scenario-dependent
  LCA results.
